# Solara Bay

An original top-down 2D open-world crime game, built for the make.fun
**[Make GTA 6](https://make.fun/bounty/gta6-01)** bounty as
[@ozami-mei](https://make.fun/u/ozami-mei).

Explore a 3200×2400 living city, drive, take on 5 story missions, dodge
the police wanted system, fight, and save your progress — all in vanilla
JavaScript, playable in a desktop browser from static files, no network
needed.

## Play

Open `game/index.html` in a desktop browser, or serve the folder:

```sh
python3 -m http.server
# then open http://localhost:8000/game/
```

## Features

- Open-world city with traffic, pedestrians and police AI
- Driving and on-foot combat
- 5 story missions with a wanted level system
- HUD, minimap, WebAudio sound and music
- Save progress in localStorage
